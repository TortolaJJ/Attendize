# Tarea 2 – Propuesta y planificación de modernización de Attendize

## Proyecto: TechFest

Este directorio contiene la documentación correspondiente a la Tarea 2, cuyo objetivo es proponer y planificar la modernización de Attendize v2.8.0 para mejorar la gestión de asistentes y el control de acceso al evento TechFest.

La propuesta busca modernizar la interfaz, facilitar el registro y consulta de asistentes, gestionar las entradas y salidas y mejorar la organización de la información.

## Tecnologías previstas

- Laravel.
- React y TypeScript, según la compatibilidad con el proyecto existente.
- Inertia.
- MySQL.
- Git y GitHub.
- Visual Studio Code.

## Alcance general

La modernización propuesta se centra principalmente en:

- Mejorar la interfaz de usuario.
- Consultar y gestionar asistentes.
- Registrar entradas y salidas.
- Almacenar la información en MySQL.
- Validar los datos introducidos.
- Consultar métricas básicas de asistencia.

## Estado del proyecto

La documentación recoge la propuesta y planificación de las mejoras. La implementación funcional y las pruebas se realizarán en las fases posteriores del proyecto.
