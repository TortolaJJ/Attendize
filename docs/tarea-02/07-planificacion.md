# 07. Planificación del proyecto – Attendize TechFest

## 1. Objetivo

Este documento establece la planificación del proyecto de modernización de Attendize v2.8.0 para TechFest. Se organizan las tareas por fases, indicando sus objetivos, actividades y resultados esperados.

## 2. Fases del proyecto

| Fase | Actividades | Resultado esperado |
|---|---|---|
| 1. Análisis inicial | Revisar Attendize, estudiar su funcionamiento y detectar necesidades. | Conocer el estado actual de la aplicación. |
| 2. Propuesta y alcance | Definir objetivos, funcionalidades y prioridades. | Propuesta de modernización. |
| 3. Diseño y prototipo | Preparar las pantallas y definir la arquitectura y los datos. | Prototipo y documentación técnica. |
| 4. Planificación | Identificar riesgos, sostenibilidad y criterios de validación. | Documentación de planificación completa. |
| 5. Implementación futura | Desarrollar las mejoras aprobadas en la interfaz y el control de acceso. | Funcionalidades implementadas. |
| 6. Pruebas futuras | Comprobar formularios, permisos, entradas, salidas y métricas. | Resultados de las pruebas. |
| 7. Entrega | Revisar documentación, repositorio y evidencias. | Proyecto documentado y preparado para entregar. |

## 3. Orden de trabajo

El proyecto se desarrollará siguiendo un orden progresivo:

1. Analizar la aplicación Attendize existente.
2. Definir las necesidades de TechFest.
3. Establecer los requisitos y criterios de aceptación.
4. Diseñar los prototipos de las pantallas.
5. Documentar la arquitectura y el modelo de datos.
6. Identificar riesgos y medidas preventivas.
7. Analizar la digitalización y sostenibilidad.
8. Preparar la validación y las pruebas.
9. Revisar y entregar toda la documentación.

## 4. Prioridades

Las funcionalidades se organizarán según su importancia:

**Prioridad obligatoria:**
- Consultar el listado de asistentes.
- Registrar y editar asistentes.
- Registrar entradas y salidas.
- Guardar los datos en MySQL.
- Validar los formularios.
- Mostrar métricas básicas de asistencia.

**Prioridad deseable:**
- Búsqueda y filtrado de asistentes.
- Calendario de eventos.
- Gráficos adicionales.
- Gestión de incidencias.

**Prioridad opcional:**
- Nuevos roles de usuario.
- Exportaciones avanzadas.
- Mejoras visuales adicionales.

## 5. Seguimiento del proyecto

Para controlar el avance se utilizará Git y GitHub. Se trabajará en la rama `tarea-02-planificacion`, manteniendo los documentos organizados dentro de `docs/tarea-02/`.

Se utilizarán etiquetas de Git para identificar el inicio y la entrega de la tarea:

- `tarea-02-inicio`
- `tarea-02-entrega`

Cada documento se revisará antes de incorporarlo al repositorio.

## 6. Posibles desviaciones

Si alguna tarea requiere más tiempo del previsto, se dará prioridad a las funcionalidades obligatorias. Las funcionalidades deseables y opcionales podrán aplazarse si es necesario para completar correctamente los objetivos principales.

## 7. Conclusión

La planificación permite organizar el trabajo de modernización de Attendize de forma ordenada, estableciendo prioridades y facilitando el seguimiento de cada fase. De esta manera, se pretende conseguir una solución funcional, segura y adaptada a las necesidades de TechFest.
